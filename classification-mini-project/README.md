# Мініпроєкт: «Порівняння моделей класифікації» (Практичні роботи №4-7)

##  Постановка задачі
Мета проєкту - побудувати відтворюваний пайплайн машинного навчання, дослідити класичні алгоритми бінарної класифікації для набору даних **Heart Disease**, налаштувати гіперпараметри лише за допомогою крос-валідації та провести одноразове незалежне тестування найкращої моделі.
- **Позитивний клас:** `1` (наявність ознак серцевого захворювання).
- **Основна метрика:** F1-macro.

##  Структура репозиторію
- `data/heart_disease.csv` - очищений набір даних.
- `notebooks/PR04_Fesenko_Sofiia.ipynb` - єдиний наскрізний Jupyter Notebook з усіма експериментами.
- `models/best_classifier.joblib` - збережений фінальний пайплайн (Логістична регресія).
- `reports/cv_model_comparison.csv` - зведена таблиця результатів крос-валідації.
- `reports/final_test_metrics.csv` - фінальні метрики на тестовій вибірці.

##  Методика експерименту
1. Виконано стратифікований поділ вибірки у співвідношенні **80% (навчання) / 20% (тест)** (`random_state=42`, `stratify=y`). Тестова вибірка залишалася закритою до фінального етапу.
2. Налаштовано єдину схему **5-кратної крос-валідації** (`StratifiedKFold`).
3. Усі перетворення (імпутація медіаною/модою, стандартизація `StandardScaler`, One-Hot кодування) об'єднані в єдиний `ColumnTransformer` та `Pipeline` усередині кожного фолду (запобігання витоку даних).

##  Фінальна модель та результати тесту
* **Обрана модель:** Логістична регресія (з L2-регуляризацією та параметром C = 10). Вона показала найкращу збалансованість F1-міри та найвищу стабільність між фолдами крос-валідації.
* **Фінальні результати на закритому тесті:**
  - **Test Accuracy:** `0.8689`
  - **Test F1-macro:** `0.8685`
  - **Test ROC AUC:** `0.9632`
